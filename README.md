# Gim SaaS
  
  La idea es hacer una plataforma donde se puedan gestionar x cantidad de gimnasios de manera independiente cada uno, el dueño del gimnasio a podra gestionar su negocio y el dueño del gimnasio b no tendra relacion alguna con los datos de otros gimnasios aparte del de el

Stack:
-Backend
  +Python(Fastapy, SQLalchemy)
-Base de datos
  +PostgreSQL
-Frontend
  +React
-Servidor
  +Render
